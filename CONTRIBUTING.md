# Contributing

- Read `CLAUDE.md`. The rules apply to people too.
- Sign off every commit (`git commit -s`); this project uses the Developer Certificate of Origin, not a CLA. Contributions are Apache-2.0 under §5 of the license.
- One PR per `TASKS.md` item. Fill in the PR template; the leak question is required.
- Do not change `spec/vectors/` or `spec/vectors.sha256` in a PR that also changes code. A vector change is a spec change and is reviewed on its own.
- Nothing from any employer's systems, ever. If you are not sure, it does not go in.
