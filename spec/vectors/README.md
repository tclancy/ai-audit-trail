# Vectors

Generated by `tools/vectors-go`, which is the reference for canonical bytes and is **not** the code under test. Do not edit by hand. Do not regenerate in a PR that also changes code.

- `positive/*.json` — one canonical line each (no trailing newline in the file beyond the line's own `\n`); sidecar `*.hash` holds `sha256(line)`.
- `negative/*.json` — a line that must be rejected; sidecar `*.expect` holds the verifier check number (SPEC §5) and exit code.
- `anchor/` — a submission and a sink receipt under their domains.
- `../vectors.sha256` — manifest; CI runs `sha256sum -c`.

Required set: see SPEC §11.
